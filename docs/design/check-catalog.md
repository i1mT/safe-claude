# 检测项清单

版本：`draft-2`；2026-11-11。共 **64 项**，所有适用且可持续采集的项目参与安全分扣减。以下为首版初始权重；分值可配置、版本化发布。

## 采集与执行规则

- `本地`：从操作系统、Claude 有效配置或已登记进程读取最小元数据。
- `探测`：通过此次 Claude 等价路径主动检测；未完成视为 unknown。
- `信誉`：授权 IP 数据供应商与版本化数据库。
- `历史`：本产品已采集的观测，按 context、provider、出口前缀和 networkEpoch 归档。
- `适配`：需要阶段 01 验证稳定读取能力；仅使用配置/状态/错误计数，不读凭据、聊天、记忆正文或项目源码。
- 规则列出的前提不成立为 not_applicable；前提成立而采集失败为 unknown，并进入完整度与 hold 策略。
- 轻项累积和重项都可触发启动与运行中阻断。默认无仅提示类规则。

## E：本机与出口一致性（10 项）

| ID | 触发条件 | 扣分 | 采集/前提 |
|---|---|---:|---|
| E01 | 当前目标出口地理时区与系统时区不一致 | 6 | 信誉时区 + 系统；比较 IANA 候选集合，处理 DST/多时区国家 |
| E02 | Claude 进程有效 TZ 与系统时区不同 | 4 | 本地进程上下文；未设 TZ 时用 runtime 验证后的继承语义 |
| E03 | 系统首选语言与出口地区语言集合不一致 | 3 | 系统语言 + 版本化地区语言映射 |
| E04 | 此次进程 locale 与系统首选语言不同 | 3 | 有效 locale；去除通用 C/POSIX 的工具默认值后判定 |
| E05 | LANG 与实际生效 LC_ALL/LC_* 的语言/地区冲突 | 2 | 本地；按 runtime 实际优先级解释 |
| E06 | 系统区域格式的国家与目标出口国家不同 | 3 | 系统区域设置 + 信誉；不从国籍推断 |
| E07 | 本机时间相对可信时间源偏移超过 30 秒 | 6 | 时间元数据；超过 5 分钟升至 15，替代低档 |
| E08 | 系统关闭自动时间同步 | 2 | 本地；有明确企业时间源时由适配器识别实际同步状态 |
| E09 | 检测到虚拟化来宾或 SSH 远程 shell | 3 | `kern.hv_vmm_present` 识别内核报告的 Hypervisor 来宾；严格验证进程环境中的 `SSH_CONNECTION`/`SSH_CLIENT`/`SSH_TTY` 结构，只保存命中标记、不保留地址或 TTY 路径。远端其他类型仍待适配；未命中不推断其他远端环境安全 |
| E10 | 会话内系统时区/语言/区域设置发生变化 | 6 | 本地事件；单次系统设置保存归为一事件 |

一致性不等于把所有值强行改成同一种语言或同一个国家。产品检测、解释并计分，不自动改写系统语言、时区或请求指纹。E01 与 E03 为不同机制，分别扣分；同一 locale 字段通过 E04/E05 重复描述同一冲突时取较高值。

## G：本机使用与客户端状态（8 项）

| ID | 触发条件 | 扣分 | 采集/前提 |
|---|---|---:|---|
| G01 | 本机用户会话并发超过预算 4 | 8；超过 8 为 16 | 已登记会话；排除 helper/supervisor/standby |
| G02 | 60 秒内用户新会话启动次数超过预算 10 | 6；超过 30 为 15 | 启动事件；仅保存授权顶层启动时间戳并跨 Agent 重启恢复，不保存会话标识；排除内部自启动和主动重试探测 |
| G03 | 同会话错误/重试元数据 60 秒内超过 10 次 | 10 | Claude Code StopFailure 固定错误类别；不读取错误详情/消息 |
| G04 | 本机认证失败元数据 10 分钟内至少 3 次 | 15 | Claude Code StopFailure 认证/账号类别；不主动反复登录测试 |
| G05 | 不同本机 Claude 客户端/安装同时持有活跃会话 | 6 | 可识别的本机进程与会话元数据；不推断其他设备 |
| G06 | 当前生效模型已被官方标为 deprecated/retired，或官方生命周期清单过期/无法解析 | 2 | 当前启动 `--model`、进程模型环境变量及有效 settings 模型字段；只保留严格校验后的模型标识。官方 alias 按带日期快照解析；未知 alias、provider deployment、多个冲突来源和缺少显式模型保持 unknown，不读用户问题 |
| G07 | 当前会话记忆功能关闭，或启用后有效记忆元数据计数为 0 | 关闭 2；启用但为空 1 | 经验证的配置状态与默认 memory 目录 `.md` 文件元数据；同时存在 `CLAUDE_CONFIG_DIR` 时支持安全的 `CLAUDE_CODE_PROJECT_DIR_NAME` 目录名覆盖；用户/托管 settings 和显式 `--settings` 的唯一自定义 `autoMemoryDirectory` 只做文件元数据盘点。项目来源、设置冲突、长路径 hash、worktree 映射或不安全目录保持 unknown；不读取正文、不保留或上报路径和文件名 |
| G08 | 10 分钟内本机认证方式/客户端身份上下文切换至少 3 次 | 8 | 受控的 Claude 启动事件和 settings 认证方式类别；只保存 OAuth/managed、API key、auth token、Bedrock、Vertex、key helper 类别及时间戳，不保存 token、邮箱、账户凭据或命令值；账号身份本身不可读取时不伪造身份切换 |

G03/G04 使用 Claude Code 官方 StopFailure hook 的固定错误类别和 session_id；仅持久化 session_id 摘要、类别和时间，不读取错误详情/消息字段。G03 的事件数是 API 错误结束 turn 的保守代理，不能冒充底层自动 retry 次数。安装器会将 hook 合并进用户设置并保留原有 hook；未安装该 hook、无法确认事件存储或版本不支持时规则继续 critical unknown/hold。G06 使用官方模型生命周期快照，超过 45 天视为过期并保持 critical unknown；更新快照时按其正式生效日期处理，不提前启用未来状态。

## H：检查完整度（4 项）

| ID | 触发条件 | 扣分 | 采集/前提 |
|---|---|---:|---|
| H01 | 核心路径/上下文检查未知或过期 | 20 | 每个根因一次；同时 hold |
| H02 | 已启用的辅助信誉/一致性数据源不可用 | 每独立源 5，最高 15 | 同源缺失不重复；默认 hold |
| H03 | 必要来源或状态相互冲突，尚未复核 | 10 | 每个冲突根因一次；同时 hold |
| H04 | 首次安装/重置后历史未达稳定性所需窗口 | 3 | 每次评估只扣一次；其他已完成检查仍正常计分 |

H02 的上限只约束同一“数据缺失”规则的重复源数量，不是对全部辅助异常设组上限。真正已观测的多个异常分别累加。

## 排除资料与场景

| 资料 | 排除原因 |
|---|---|
| 支付方式、卡片类型、账单、充值 Credits | 无稳定持续采集需求，不收集支付资料 |
| 实际账号创建时间、注册渠道/邮箱信誉、最初注册 IP | 本机无法可靠持续核验，不能拿本地文件年龄替代 |
| 订阅购买/升级时机、KYC 状态与身份资料 | 不属于可持续本机环境观测 |
| 其他设备/手机的登录和使用次数 | 本机没有可靠全局视图；本机多客户端已有 G05 |
| 聊天内容、国籍陈述、问题重复程度、记忆正文 | 不读取正文做评分；重复错误、记忆开关与可读索引计数另有适配 |
| 浏览器 Canvas/WebGL 指纹 | 首版保护 CLI，不安装浏览器探针；浏览器保护阶段另建真实上下文 |
| 实际额度消耗/账号级调用量 | 首版无账号计费状态来源；本机并发/启动/重试已有 G 类 |

## 回放示例

1. 机房 IP −8、VPN 标签 −6、IP/时区不一致 −6、IP/语言不一致 −3：`S=77`，阻断，运行中同样开始处置。
2. 仅 IP/时区不一致 −6、首次无历史 −3：`S=91`，允许，仍展示两条扣分。
3. VPN −6、机房 −8、系统区域与出口不符 −3、关闭记忆 −2：`S=81`；再发生进程语言不符 −3 → `S=78`，阻断。
4. 第三方信誉接口失效：扣 H02，但不输出“完整安全分 95”；显示检查未完成并 hold。
5. 同一次出口国家变化被两个来源观察，且附带 ASN/IP 变化：只扣对应变更规则一次；时区和语言一致性独立再计算。
